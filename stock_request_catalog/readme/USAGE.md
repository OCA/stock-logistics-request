To use this module:

1.  Go to *Inventory > Operations > Stock Requests > Stock Request Orders* and
    open (or create) a draft order.
2.  Set the warehouse and location (and any other order-level values); the
    lines inherit them.
3.  On the *Items* tab, click the *Catalog* button below the lines.
4.  Browse the products; use the +/- controls (or type a quantity) to set how
    much of each product to request. On-hand stock is shown on each card.
5.  Click *Back to Stock Request*: a request line is created for every product
    with a non-zero quantity.

The catalog is only available while the order is a draft. Reopening it shows the
current quantities and lets you adjust or remove them.
